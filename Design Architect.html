Code Smell
Detection System

A static analysis tool built in C++ using OOP principles to parse source code and detect common code smells in test environments. Full architectural walkthrough.

01 · Processing Pipeline
01
Source Input
Raw .cpp / .h file paths ingested via CLI or config file
02
Lexer / Tokenizer
Splits source text into token stream (keywords, identifiers, operators)
03
AST Builder
Constructs lightweight abstract syntax tree from tokens
04
Smell Analyzers
Each detector walks the AST independently and collects violations
05
Report Engine
Aggregates findings; outputs to console, JSON, or HTML
02 · Class Hierarchy / Inheritance
  • SmellDetector // pure abstract base
    • LongFunctionDetector // line count threshold
    • LongParameterListDetector // param count > N
    • DuplicateCodeDetector // hash-based block similarity
    • GodClassDetector // method + field count
    • DeadCodeDetector // unreferenced symbols
    • MagicNumberDetector // inline literal constants
    • DeepNestingDetector // brace depth analysis
  • ReportFormatter // pure abstract
    • ConsoleFormatter
    • JSONFormatter
    • HTMLFormatter
  • ASTNode // base node
    • FunctionNode
    • ClassNode
    • BlockNode
    • ExpressionNode
03 · Core Class Definitions
SmellDetector
// abstract base class
  • ─ string name
  • ─ Severity severity
  • ─ DetectorConfig config
  • + virtual analyze(ASTNode*) = 0
  • + virtual getReport() → Report
  • # addViolation(location, msg)
SourceParser
// orchestrates lexing + AST
  • ─ Lexer lexer
  • ─ ASTBuilder builder
  • ─ SymbolTable symbols
  • + parse(filepath) → ASTNode*
  • + getSymbolTable() → SymbolTable&
DetectionEngine
// manages & runs all detectors
  • ─ vector<SmellDetector*> detectors
  • ─ ReportFormatter* formatter
  • + registerDetector(SmellDetector*)
  • + runAll(ASTNode*)
  • + generateReport()
Violation
// data model: one finding
  • ─ string filePath
  • ─ int lineNumber
  • ─ string smellType
  • ─ string message
  • ─ Severity level
  • + toString() → string
Report
// aggregate result container
  • ─ vector<Violation> violations
  • ─ map<string, int> smellCounts
  • ─ int totalFiles
  • + addViolation(Violation)
  • + getSummary() → string
DetectorConfig
// tunable thresholds per detector
  • ─ int maxFunctionLines
  • ─ int maxParams
  • ─ int maxNestingDepth
  • ─ float duplicateThreshold
  • + loadFromFile(path)
  • + validate()
04 · Detectable Code Smells
Smell Detection Strategy AST Node Target Severity Config Key
Long Function Count lines/statements in function body FunctionNode High maxFunctionLines
Long Parameter List Count parameters in function signature FunctionNode Med maxParams
God Class Tally methods + fields; flag if both exceed thresholds ClassNode High maxClassMethods, maxFields
Duplicate Code Rolling hash over statement sequences; cosine similarity BlockNode High duplicateThreshold

05 · Data Flow: Input → Output
CLI / Config
User specifies file paths, detector flags, severity filter, and output format via argv or .smellrc config file
DetectorConfig, file list
Lexer
Reads raw source characters → emits Token stream (type, value, line/col). Handles comments, strings, preprocessor directives
vector<Token>
ASTBuilder
Consumes token stream using recursive-descent parsing → constructs tree of ASTNode* (FunctionNode, ClassNode, BlockNode, ExpressionNode)
ASTNode* (root)
DetectionEngine
Iterates registered SmellDetector* list. Each detector walks the AST via Visitor pattern (accept/visit). Violations pushed into detector-local list
vector<Violation> per detector
Report
DetectionEngine aggregates all violations into a Report object. Sorts by file, line, severity. Computes per-smell counts and totals
Report object
ReportFormatter
Polymorphic formatter accepts Report → renders to target medium. Console: colored terminal output. JSON: machine-readable. HTML: browser-ready
stdout / .json / .html
06 · OOP Design Patterns Applied
Strategy
// swappable detectors
  • → SmellDetector* can be swapped at runtime
  • → DetectionEngine holds vector of base pointers
  • → Enables plugin-style extensibility
Visitor
// AST traversal
  • → ASTNode has accept(Visitor&)
  • → Each SmellDetector is a Visitor
  • → Decouples traversal from node types
Factory
// detector creation
  • → DetectorFactory::create(smellName)
  • → Centralizes object creation
  • → Config-driven detector activation
Template Method
// analyze() skeleton
  • → Base SmellDetector::analyze() handles boilerplate
  • → Subclasses override doAnalyze()
  • → Ensures pre/post hooks always run
